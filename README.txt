# Bright Future Academy — Coaching Center Demo

A portfolio/demo website for a local tuition or coaching center.

## Files

- `index.html` — page structure/content
- `style.css` — responsive design
- `script.js` — mobile menu, WhatsApp links, enquiry form

## How to run

1. Put all three files in the same folder.
2. Double-click `index.html`.
3. It will open in your browser.

## Before showing a real client

Replace the demo:
- Academy name
- Phone/WhatsApp number
- Email
- Address
- Courses
- Timings
- Testimonials
- Images/logo

In `script.js`, change `WHATSAPP_NUMBER` to the client's WhatsApp number.

This demo intentionally uses a fictional academy and sample contact details.
